# 绿色工厂十五年

一款关于一座化工厂的单文件网页叙事游戏。

同一座厂、同一段十五年，你可以站在五个不同的位置上各走一遍——
厂长的一个批复，是工程师的一次签字、工人的一个夜班、
销售的一通电话、监管员的一份笔录。

**[▶ 开始游戏](https://Zhipeng1.github.io/green-factory-15-years/)** 或https://green-factory-15-year-factory-d9g6t2w38a5fbdb60.webapps.tcloudbase.com/ 

## 五条角色线

| 角色 | 你要面对的 |
|---|---|
| 厂长老许 | 三条产线、四百多号人、一根从早冒到晚的烟囱 |
| 工程师小陈 | 签字的是你，出事担责的也是你 |
| 操作工小刘 | 设备换新是双刃：不用再闻那个味，可你那身手艺也一夜作废 |
| 销售林薇 | 你卖的东西，厂里做不到 |
| 监管员小方 | 你的权力足以关掉一家厂，却不足以让一条河变干净 |

每年桌上摆着好几件事，你的精力只够办其中两件。
没办的不会消失，年底会自己有一个结果。

## 关于真实性

游戏里的排污许可证、危废联单、碳配额、VOCs 治理设施、工伤认定、
行政复议、《绿色工厂评价通则》十五项指标，都按真实制度写。
罚款金额落在法定区间内，工资和奖金按真实量级估算。

## 技术

单个 HTML 文件，无框架、无后端、无外部请求。双击即玩。
仅使用 localStorage 在本机记录已解锁的结局。
